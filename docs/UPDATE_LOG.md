## 운영 점검 및 HTTPS 개선 (2026-10-11)

- Cloudflare에 `HTTPS for public website only` 리디렉션 규칙을 적용함. `apsconsulting.kr`, `www.apsconsulting.kr`의 HTTP 요청을 같은 호스트의 HTTPS로 308 이동하며 경로와 쿼리 문자열을 보존함.
- 적용 범위는 공개 홈페이지 두 호스트로 한정함. 관리자 웹, 앱 백엔드, 업데이트 서비스에는 규칙을 적용하지 않음.
- 두 호스트의 주요 페이지 6개와 JS/CSS/번역/약관 자산 4개 경로에서 HTTPS 이동 및 최종 200 응답을 확인함. www 번역 파일의 일시적 시간 초과는 재확인 시 최종 200 응답함.
- 실제 브라우저에서 HTTP 상담 페이지 진입 후 HTTPS 전환, 상담 폼·국가 목록·약관 보기·한국어/영어 전환과 콘솔 오류 없음 확인. 상담 API의 CORS 및 빈 입력 검증, 관리자 웹 접근, 앱 백엔드 준비 상태·미인증 접근 거부, 업데이트 feed 응답도 확인함.
- 실제 상담 접수, 파일 업로드, 관리자 로그인 후 저장, Electron 앱의 로그인·실시간 연결 전체 과정은 이번 점검에서 실행하지 않음.
- 복구가 필요하면 Cloudflare의 위 리디렉션 규칙을 비활성화함.
